Just a simple collaborative game project made in Godot 4.5

# About
This is test game that utilise Godot 3D. Overall just a prototype that involves shooting, enemy, health mechanic as well as basic first person shooter moveset. This is intended to be a team-building project that serves as a lesson in making a 3d game as well as maintaining version control. 

# Goals
- Basic Moveset
- Shooting
- Health Mechanic
- Enemies AI and Pathfinding
- Controller Compatibility
- ~~Added Version Control~~
